# 轻级浏览器（QingJi Browser）

一款功能对标 Chrome 的安卓浏览器，Kotlin + Jetpack Compose（Material 3）开发。

- **应用名称**：轻级浏览器
- **包名**：`com.lightbrowser`
- **minSdk 29（Android 10）/ targetSdk 36（Android 16）/ compileSdk 36**
- **构建产物**：`轻级浏览器-v1.0.3.apk`（debug 签名，可直接安装）

## 版本记录

### v1.0.3（2026-09-14）
- **修复：地址栏输入内容时应用闪退的问题**（如在保留浏览记录的情况下输入「今日新闻」等关键词必现闪退）。
  原因：历史记录中若存在多条相同标题的记录，搜索联想结果会出现重复文本，建议列表 LazyColumn 使用「类型+文本」作为内容 key，重复 key 直接抛出异常导致闪退。
  修复：联想结果在下发前按展示文本去重；建议列表不再使用内容 key，彻底消除该崩溃路径。
- **优化：点击搜索框进入编辑态时的界面过渡。**
  编辑态下顶栏背景与页面同色，不再出现突兀的方形色块，且颜色切换带过渡动画；地址栏在「展示态/编辑态」之间切换时增加淡入淡出动画；搜索建议面板改为编辑态始终显示（无建议时显示空白页底），并带淡入+展开动画。

### v1.0.2（2026-09-13）
- **修复：部分网页渲染异常（页面内容只显示一半高度、下方大片空白）的问题**，典型如 QQ 官网等依赖视口高度布局的页面。
  原因：在输入网址时软键盘会压缩 WebView 容器高度，键盘收起后部分机型（MIUI/HyperOS 等）上 WebView 不跟随容器恢复尺寸，页面视口高度停留在被压缩的值。
  修复：监听网页容器尺寸变化，尺寸变化时强制 WebView 按新尺寸重新排版；同时固定 WebView 为 MATCH_PARENT 布局参数。

### v1.0.1（2026-09-13）
- **修复：顶部地址栏在部分机型（MIUI/HyperOS 等）上不可见的问题。**
  原因：新标签页（主页）在 Compose 界面下层仍挂载了一个空白 WebView 原生视图，部分系统上该视图会越界绘制，遮挡顶部栏。
  修复：主页状态下不再创建/挂载 WebView（纯 Compose 渲染）；浏览网页时 WebView 改为在 AndroidView 工厂回调中创建，并对内容区与 WebView 容器增加边界裁剪（clipToBounds）；切换标签页时按标签 ID 强制重建 WebView 容器，保证显示正确。

### v1.0.0（2026-09-13）

## 功能清单（对标 Chrome）

| 模块 | 功能 |
| --- | --- |

## 安卓版本适配

- **Material You 动态取色**：Android 12+ 跟随壁纸配色，可关闭
- **边到边（Edge-to-Edge）**：状态栏/导航栏沉浸式，图标颜色随深浅主题切换
- **预测性返回手势**：`enableOnBackInvokedCallback`，配合 Navigation 转场
- **SplashScreen API**：启动画面
- **网页深色模式**：`WebSettingsCompat` 算法级网页调暗
- **自适应图标 + 单色图标**：适配 Android 13+ 主题图标

## 技术栈

Kotlin 2.1 · Jetpack Compose（Material 3, BOM 2025.06）· Navigation Compose · Room（书签/历史/标签持久化）· DataStore（设置）· Android System WebView + androidx.webkit · Coroutines/Flow · AGP 8.11 / Gradle 8.13

## 已知限制

- 无痕标签的 Cookie 与常规标签共享存储（Android WebView 全局 CookieManager 限制），无痕仅保证不写入历史、不持久化缓存；
- blob: / data: 协议的网页内下载暂不支持；
- 广告拦截为内置域名列表，非完整 EasyList 规则。
